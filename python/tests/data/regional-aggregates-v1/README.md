# Native regional aggregate fixtures

These small Vortex 0.93.0 inputs are generated by
`shardloom-vortex/examples/native_regional_uat_fixture.rs` with mode `public`.
Run the example with the existing storage guard and an empty local output
directory. It creates new files only; it does not execute queries.

The seven profiles contain 71 rows (zero for `empty`), exact signed/unsigned
64-bit values, nullable columns and independently zoned fields. Most zone
lengths are 8/4/8; `independent` uses 8/4/6. `missing-min` omits the signed
minimum declaration, `all-null` makes that field entirely null,
`nullable-predicate` omits the first eight selector values, and `flat` has no
zone tables. Whole-file statistics are disabled. The Python test calculates
complete expected values independently; it never uses another query engine.

This fixture layout is explicit test input, not a writer-default change or a
query-execution fallback. Generation and validation receipts are retained in
the regional aggregate experiment evidence.
