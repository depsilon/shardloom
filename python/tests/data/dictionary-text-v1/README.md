# Native dictionary text fixtures, version 1

These six small Vortex files are generated by
`shardloom-vortex/examples/native_dictionary_uat_fixture.rs` in `public` mode.
Each nonempty file has 71 rows in three explicit chunks (23, 24 and 24 rows),
with a nonnullable `row_id` and nullable UTF8 `value`.

- `dictionary`: repeated Unicode, whitespace, embedded NUL, empty and null
  values. The same codes name different values in different chunks.
- `sparse`: sixteen-entry domains with four observed entries, including a null
  value, plus a long unreferenced valid value.
- `all-null`: null codes and codes naming a null value.
- `unique`: a distinct domain value for each row, retaining a domain at least
  as large as the chunk.
- `flat`: the repeating dictionary's logical population in flat native arrays.
- `empty`: zero rows with the same declared schema.

The flat writer serializes the supplied native arrays without a compression
heuristic. The independent Python population and result oracle live in
`python/tests/native_dictionary_text_cases.py`. Public tests verify complete
results and schemas through all five entry points, actual dictionary work,
changed-source rejection, retained output ownership and write/reopen behavior.

The larger work fixtures remain outside the repository. These files establish
correctness coverage and do not make a performance claim.
