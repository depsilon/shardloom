ShardLoom is a unified data processing engine. Use SQL or DataFrames in Python,
run queries from the command line, or embed the engine in an application.
Readers and writers connect supported formats to the same engine.

The published technical preview supports specific local analytical workflows.
This guide identifies available operations, types, and platforms, alongside
[remaining work and release criteria](/field-guide/limitations#release-and-readiness).
