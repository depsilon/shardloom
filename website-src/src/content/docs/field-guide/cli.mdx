## Install the executable

For macOS/Linux with Homebrew:

```sh
brew install depsilon/tap/shardloom
shardloom status --format json
```

The Python wheel also bundles a compatible CLI. Exact download artifacts and
source builds are linked from [installation](/field-guide/start-local-proof).

complete paid-order values as the Python and SQL examples. The 256 MiB and two
lanes are illustrative caller allocations.

it does not remove the result size limits or truncate larger data.

## Find an operation

| Task | Command family |
| --- | --- |
| Execute an admitted plan | `run` |
| Prepare a reusable Vortex artifact | `prepare` |
| Inspect planned work and boundaries | `route`, `explain`, `estimate` |
| Inspect capabilities or setup | `capabilities`, `status`, `doctor` |
| Read exact command arguments | `help COMMAND` |
| Discover machine-readable command metadata | `command-metadata --format json` |

The installed registry is the authority for arguments and available commands.
In 0.6.0 the complete metadata also includes maintainer smoke/rehearsal commands;
they are tools for contributors, not alternate ways to execute a production query.
The [source reference](/field-guide/reference) distinguishes application and
maintainer discovery for development builds.

Plan/capability inspection is not query execution. Writers require explicit
destinations and follow the [format and publication contract](/field-guide/runtime-and-io#write-results).
