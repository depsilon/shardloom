The [source API index](https://github.com/depsilon/shardloom/blob/main/docs/reference/shardloom-user-surface-index.md)
and [machine-readable inventory](https://github.com/depsilon/shardloom/blob/main/docs/reference/shardloom-user-surface-index.json)
are generated from the development export and command authorities. They label
their revision and audience; they do not redefine this release's availability.
For the installed engine, `shardloom command-metadata --format json` exposes its
machine-readable command inventory, and `shardloom help COMMAND` describes a
specific command without executing it.
