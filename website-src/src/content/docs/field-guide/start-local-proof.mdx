<a id="1-install-a-package"></a>
## Install

Use a fresh Python virtual environment, then install the named release:

```sh
python -m venv .venv
```

Activate it on macOS or Linux:

```sh
. .venv/bin/activate
```

On Windows PowerShell, activate with `.venv\Scripts\Activate.ps1` instead.

<PackagePlatforms />

The example selects `transport="native"` on Linux or macOS. On the Windows
package, use `transport="subprocess"`. This changes process isolation, not the
query engine. The Windows wheel has build and artifact inspection evidence;
it does not have the Linux/macOS native runtime coverage. The source distribution
contains no compiled engine; use the [source build instructions](https://github.com/depsilon/shardloom/blob/main/docs/getting-started/source-checkout-install.md)
if no wheel matches your platform. PyPy and other CPU/OS combinations are not
covered by these wheel tags.
