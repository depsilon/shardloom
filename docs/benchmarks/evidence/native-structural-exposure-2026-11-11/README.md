# Structural declaration exposure

`summary.json` records the complete 10,000-declaration audit and its limits.
`audit.json.gz` preserves the full matching-ID/path record, frozen declaration
source identities and nine accepted-owner source identities. `audit.py` is the
exact generating script, requiring the retained original frozen harness/design
at its declared local paths. This is not a self-contained portable runtime replay.

The audit executes no queries and does not measure engine time, source
selectivity, downstream setup cost or physical full-sort activation. Complete
case identities are checked before classifying structural paths. Owner bytes
were separately compared with Git revision
`591fdb42f6ffcd5e9003b4a5c130324d7a34a62c` before packaging.

The initial counter aggregation failed before producing a report, because a
mapping's path-list values were passed to `Counter.update`. The correction counts
its keys. The original source and failure description remain in `failure-r1`.
