# Native optimization activation evidence

Run `python3 -I -B verify.py` with Python 3.13 or newer. The verifier unpacks
validated members into a temporary local directory, uses the frozen declaration
and comparison code, and replays all complete saved answers and schemas. It
recomputes mechanism/resource checks and the fresh-session and lifecycle
decisions without loading ShardLoom, Polars or another execution engine.
Keep every `evidence.tar.gz.part-*` file alongside the verifier and manifest.
The verifier checks every part and the complete reassembled archive before
reading its members; no manual concatenation is required.

The packet includes all four complete raw result ledgers, independent reference
databases, exact candidate source bytes, supervision and validation receipts,
the prior failed preflight, and the prospective lifecycle amendment. Original
large data, comparison-environment packages and executable runtime payloads are
represented by their pre/post-run identities. Portable replay does not reopen
those external payloads or repeat the original reference computations.

Both calls in each of the five prepared lifecycles are scored. The 378 exact
accepted baseline observations are reused once; every other declared request
has one admitted observation under protocol r3. The complete earlier r2 baseline
is also included: its 7,120 fresh executions passed capture but were excluded
from performance acceptance because task-owned file inspection overlapped the
run. Its replacement was declared before examining its timings; the original
results, protocol, isolation incident and amendment remain intact. Operating
system cache state was uncontrolled throughout. Overlapping mechanism groups
must not be summed. Results are local evidence and do not authorize publication
or close competitive gates.
