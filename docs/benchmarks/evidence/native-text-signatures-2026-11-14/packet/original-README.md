# Declined native text-summary experiment

Decision: **drop**. Run `python3 -I -B verify.py` with Python 3.13 or newer.
Keep all archive parts and the manifest together. Verification reads archived source, complete
result ledgers, independent references, validation receipts and original recovery evidence.
It executes no native engine, competitor, subprocess or query.

Each runtime covers the frozen 9,040-case population: 4,150 inherited original cases,
1,380 dictionary cases and 3,510 versioned text-signature cases. Each also has 270 lifecycle
plans with two operations per plan. All 18,080 complete results and 1,080 lifecycle operations
pass, including 840 required logical exclusion witnesses.

Complete fresh engine time: 682.167470629 -> 692.796513379 seconds.
Complete lifecycle engine time: 0.520543159 -> 0.399726140 seconds.
The complete fresh total increases, so the frozen rule declines the candidate. All 4,581
individual regressions remain recorded. Faster new text cases and lifecycles do not replace
the complete-cohort decision; the accepted source/domain runtime remains the baseline.

Recovery reuses all 4,631 verified original successes, including 336 earlier source/domain
observations, without selecting by timing. Sixteen pre-collect helper failures, one interrupted
unaccepted engine observation and 4,392 never-started requests account for 4,409 new baseline
executions. The candidate executes 9,040 cases once. All original failures, stopped output,
protocol versions and corrected helper sources remain. A subsequent lock failure ran no queries;
the R3 freezer's tuple/list equality failure is retained with independent written-protocol validation.

The packet separately replays 108 complete fixture readbacks, 648 direct-provider diagnostic
scans and 108 native writer construction records. Requested segments, logical exclusions and
completed positional ranges remain separate. The diagnostics do not measure physical-device
or decoded bytes or public-operation I/O. Writer timing excludes session/provider setup and
does not establish complete first-use or ingest break-even cost.

Original paths and generations are provenance; they need not exist on the replay machine.
Native runtime, diagnostic binaries and generated fixture payloads are excluded while their
identities remain bound. Complete readbacks, raw logs, ledgers, validation records, source
revisions and the rejected patch remain. No publication or broader gate closure is implied.
