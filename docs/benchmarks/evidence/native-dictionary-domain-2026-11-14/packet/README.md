# Dictionary-domain text experiment

Decision: **retain**. Run `python3 -I -B verify.py` with
Python 3.13 or newer. Keep every archive part and the manifest together.
Verification checks transport and member identities, then replays all 11,060
complete fresh results and 80 prepared lifecycle operations against their
original requests, schemas and independent references. It verifies exact
default/native test inventories, feature and minimum-Rust checks, layout-provider
checks, installed-wheel proof and the frozen decision. It executes no native
engine, competitor, subprocess or new query.

The complete 5,530-case fresh engine total is
676.301549673 -> 668.884468618
seconds. The separate complete lifecycle engine total is
0.098959580 -> 0.077330714
seconds. Each total includes every declared operation in its own population.
These populations are not a Full43 or full10k pass. Both engine totals must
decrease to retain the candidate, without a minimum percentage threshold.

The fixed cohort contains 4,150 original text-expression and UTF8 identity
controls plus 1,380 versioned dictionary requests. All five public surfaces
exercise six native text functions, group/distinct/filter consumers, compatible
shared output and explicit flat/unique/empty/union/selected controls. Of these,
630 have declared dictionary activation; 210 work witnesses require fewer
completed text-kernel calls than their logical expression rows. Codes remain
inspected and copied. The baseline has no dictionary-work counter, so this is
not a measured baseline kernel-call comparison, zero-decode or RSS claim.

The packet retains every fresh regression, complete raw ledgers, original
references, exact candidate source and patch, all failed validation sources
and receipts, and 28 offline corruption/refusal controls. Synthetic values used
to isolate retention gates never replace an observation. All 4,903 compatible
baseline packets are reused byte-for-byte: 1,807 historical packets (including
49 earlier reuse pointers) and 3,096 successful packets from the stopped capture.
Recovery executes 627 baseline requests: 599 never started, 27 failed before
collect, and one complete but oversized capture that could not be admitted.
Its original output and clock remain preserved; its retry is selected by capture
failure, not performance. The candidate executes all 5,530 requests once.
Twenty ordinary prepared plans execute exactly two scored calls per
runtime. Public-sized shared output keeps both complete lifecycle results
inside the unchanged command-output limit; work-sized grouped lifecycles
exercise the larger inputs. No warmups, successful-observation repeats or cache
manipulation are added. Versioned workers correct literal regex construction and
use bounded lossless compression when duplicated full-result diagnostics exceed
the original 8 MiB wire limit. The decoded artifact has a 64 MiB memory bound;
the 9 MiB raw-member, row, engine-memory and other limits remain unchanged.

Cache state is uncontrolled. Requested read counters include metadata,
repeats and coalescing; they are not physical device or unique bytes. Large
input and native runtime/environment payloads are represented by their original
identities and pre/post-run receipts. Portable replay neither reopens those
payloads nor regenerates reference data. The source/helper superset is bound;
unused earlier runtime and input payloads are not current dependencies.

Original paths and generations remain historical provenance and need not
exist on the replay machine. This packet does not imply publication, release,
competitive superiority or completion of the broader investigation queue.
