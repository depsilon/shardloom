Decision: **drop**. Run `python3 -I -B verify.py` with
Python 3.13 or newer. Keep every archive part and the manifest together.
Verification checks transport/member identities, then replays all 10,028
complete fresh results and 40 prepared lifecycle operations against their
original requests, schemas and independent references. It verifies exact
default/native test inventories, the reviewed layout-provider checks and
installed-wheel proof, and recomputes the frozen decision. It executes no
native engine, competitor, subprocess or new query.

These groups are not combined into a Full43 or full10k result. Work acceptance
also requires lower completed requested file bytes for all ten frozen exposure
witnesses and exact constant-group coverage for the 810 new constant-group declarations plus 350 regional controls.

The packet retains every fresh regression, all complete raw ledgers, original
references, exact candidate source and patch, failed validation receipts/logs,
and 47 offline corruption/refusal controls. Synthetic gate-isolation values
are clearly labelled and never replace an observation. All 987 compatible
baseline packets are reused byte-for-byte; the remaining 4,027 baseline requests and
all 5,014 candidate requests run once. Each of the ten prepared plans executes
two scored calls per runtime. No warmups or routine repeats are added.

Cache state is uncontrolled. Read counters include completed requested
metadata reads, repeats and coalescing gaps; they are not device or unique
bytes. Regional source ranges, delivered payload rows and auxiliary metadata
arrays have separate scopes. Large input and runtime/environment payloads
are represented by original identities and pre/post-run receipts. Portable
replay does not reopen those payloads or regenerate reference data.

Saved original paths and generations remain historical provenance and need
not exist on the replay machine. Publication, release and completion of the
broader optimization/metadata queue are not implied.
