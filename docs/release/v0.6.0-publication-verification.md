## Remaining scope

This is a local technical preview. Package access does not establish production
certification, broad SQL/DataFrame parity, competitive superiority or untested
platform support. Vortex remains native input and the highest-fidelity output.
Unsupported execution fails explicitly, with no external query-engine fallback.
Internal Rust crates and additional package channels remain unpublished.

The [remaining-work contract](../architecture/native-local-completion-scope-2026-10-07.md)
retains all six areas and eight investigations. After this one release train,
natural-scale batch execution and source/type/destination composition remain
the implementation priorities. Allocation, recovery, destination/fanout,
platform and conditional-investigation obligations retain their existing owners.
