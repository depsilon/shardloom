# 0.3.3 dependency intake and PR cleanup

The maintainer requested PR cleanup followed by a version/publication train.
Three compatible updates are consolidated into the release-source change rather
than merged as separate dependency PRs. Each original head passed all 40 checks;
the combined release source still requires its own source and native validation.
No runtime query-engine dependency, execution fallback or new permission is added.

| Original PR | Decision | Exact change and rationale |
| --- | --- | --- |
| [1434](https://github.com/depsilon/shardloom/pull/1434) | Include; close after consolidated merge | bytes 1.11.1 to 1.12.1. Existing buffer dependency, MIT. The upstream patch fixes panic handling during allocation. |
| [1441](https://github.com/depsilon/shardloom/pull/1441) | Include; close after consolidated merge | serde, serde_core and serde_derive 1.0.228 to 1.0.229, MIT OR Apache-2.0. Derive now uses the already-locked syn 3.0.4; serialization/native tests must pass with this graph. |
| [1442](https://github.com/depsilon/shardloom/pull/1442) | Include; close after consolidated merge | CodeQL init, analyze and SARIF upload advance together to the immutable v4 commit `1c5b675653bb5c22dbe9b12b556ec555138e09fd`. Existing workflow permissions and triggers stay unchanged. |
| [1431](https://github.com/depsilon/shardloom/pull/1431) | Closed; defer compatible graph migration | Arrow/Parquet 60 and ORC 0.9 failed nine native/package/release checks and do not match the current Vortex 0.85 Arrow 58 graph. Do not create duplicate major graphs to satisfy the bot update. |
| [1450](https://github.com/depsilon/shardloom/pull/1450) | Closed; retain Vortex 0.85 | Vortex 0.86.1 failed native compatibility checks and does not preserve the existing typed allocator-denial contract. The earlier [C1 admission decision](../architecture/vortex-086-upgrade-admission-2026-09-27.md) records the concrete gate; no unchanged retest or performance claim is made. |
