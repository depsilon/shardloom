## Remaining scope

This is a local technical preview. Package access does not establish production
certification, broad SQL/DataFrame parity, competitive superiority or untested
platform support. Vortex remains native input and the highest-fidelity output;
unsupported work fails explicitly without external query-engine fallback.
Internal Rust crates and additional package channels remain unpublished.

After this train's documentation and website closeout, the
[active phase plan](../architecture/phased-execution-plan.md) resumes the bounded
`PERF-12.comparisons` workload-gap matrix, reusing accepted evidence before adding
implementation. Its 15 scoped required-contract rows and five scheduled
prerequisite/investigation rows retain their existing boundaries. The 38 optional
rows remain deferred choices; this release does not promote them into required
work or authorize another publication train.
