installation proofs pass. Publication-document integration and verification of

## Scope

This is a technical preview. Package availability does not establish production
certification, broad SQL/DataFrame parity or performance superiority. Vortex is
the highest-fidelity native output; unsupported execution fails explicitly and
internal Rust crates remain unpublished.

The [remaining-work contract](../architecture/native-local-completion-scope-2026-10-07.md)
retains all six areas and eight investigations. Natural-scale batch execution and
source/type/destination composition are the next implementation priorities.
Continuous computation, distributed individual queries, independent-job
concurrency and analytical serving retain their existing roadmap owners.
