# ShardLoom v0.2.2

Status: technical-preview patch release.

ShardLoom v0.2.2 is a follow-up release for the public local workflow and 100M-row ClickBench UAT
path. It keeps the v0.2.x no-fallback posture and focuses on making source identity cheap by
default while preserving explicit proof mode when a content digest is required.

## Included In This Release Train

- Makes local source fingerprinting metadata-only by default for public preparation routes.
- Keeps content SHA256 proof available as an explicit opt-in through `--source-fingerprint-policy
  content_digest` or `--source-content-fingerprint`.
- Preserves the Vortex-normalized public workflow boundary: compatibility inputs are prepared into
  ShardLoom/Vortex storage before query execution, and no direct local compatibility route is
  admitted as product runtime.
- Updates local UAT evidence for the official 100M ClickBench Parquet source:
  - prepare-once ingest: 271 seconds on the local Desktop test envelope
  - 43/43 queries completed with no fallbacks or external engine invocation
  - query-only elapsed total: 215.979 seconds
  - query-only geometric mean: 1.518 seconds
- Fixes release-user-surface build warning coverage for feature-gated source-fingerprint code.

## Release Boundaries

This release does not authorize production superiority claims, hidden fallback execution, Spark or
DataFusion delegation, object-store/lakehouse production support, Foundry production support,
distributed runtime claims, or public Rust crate publication.

Every channel proof must preserve:

```text
fallback_attempted=false
external_engine_invoked=false
```

Publication proof should be recorded through the selected v0.2.2 channel transcripts after the
GitHub, PyPI, and Homebrew release steps complete:

- GitHub release: `docs/release/channel-proofs/github-prerelease-v0.2.2-transcript.json`
- TestPyPI: `docs/release/channel-proofs/testpypi-v0.2.2-transcript.json`
- PyPI: `docs/release/channel-proofs/pypi-v0.2.2-transcript.json`
- Homebrew tap: `docs/release/channel-proofs/homebrew-v0.2.2-transcript.json`
