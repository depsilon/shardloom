## Offline replay

Use Python 3.11 or newer. After relocating this directory, run:

```sh
python3 -I verify.py --require-controls
```

From the matching checkout, also compare every final source input:

```sh
python3 -I docs/release/evidence/native-wide-schema-2026-11-09/verify.py --require-controls --repo-root .
```

Replay validates saved sources, commands, logs, identities and control outcomes.
It does not build, install, execute native queries, access the network or require
the original scratch directories. Actual subprocess controls reject missing
roles/tests, failed native acceptance, installed skips, changed source/runtime,
old builds, replaced frozen expectations, omitted original failures, altered
prior-main results, unsafe archive paths and checksum corruption. Temporary
mutated payloads were removed after each observation; the original packet was
unchanged. Their logs and mutation identities are in `corruption-controls.json`.

## Boundaries

This is local macOS arm64 acceptance for matching source builds after 1.1.0.
Hosted PR checks, review, merge and exact-main acceptance are separate results;
this frozen packet does not claim them. Published 1.1.0 packages are unchanged.

Depth 24, serialized declaration/JSON byte limits, physical IPC validation and
format representation limits remain. Provider/schema credits are ownership
accounting, not a whole-process RSS bound; detached caller-owned names/DTypes,
arbitrary extensions and unrelated provider scratch remain outside those
container owners. Vortex remains native input and highest-fidelity output,
without external-engine fallback. No benchmark, performance superiority,
package publication, whole item 19, deep-traversal or CG-1 through CG-23
completion is claimed.
