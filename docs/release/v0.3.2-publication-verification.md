website verification remains pending. This release is a technical preview.

## Publication validation

The package-channel gate passed with dependency and release-dry-run reports from
the exact release-source CI run. Version synchronization, generated support docs,
documentation/product status, local/source packaging, governance, website/static
assets and inclusion checks passed. Astro reported zero errors, warnings or hints;
the site build generated 45 pages. The four focused release/proof Python modules
passed 260 tests with two existing optional-dependency skips.

The architecture audit still reports 132 open development checklist items.
An initial strict invocation returned blocked; the existing `--allow-blocked`
audit mode then completed with those items still explicit. Neither result is
production-readiness evidence. Independent artifact-pin cross-check and primary
diff review found no remaining actionable issues.

## Scope

The [release notes](v0.3.2-release-notes.md) cover shared public I/O repairs and
removal of redundant native handoff work. Unified all-I/O physical-layout
optimization remains follow-up: native Vortex preparation preserves the existing
layout, and general completed results still use bounded scalar-to-typed builders.
The earlier plain-Vortex measurements are single-pulse observations on a frozen
pre-hardening binary, not new release measurements or comparative ranking evidence.
Broader production readiness, capability parity and performance superiority remain
unclaimed. Internal Rust crates remain unpublished.
