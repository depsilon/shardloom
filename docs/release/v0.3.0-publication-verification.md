# v0.3.0 publication verification

Status: GitHub, TestPyPI, PyPI and Homebrew 0.3.0 publication and installation
verification passed September 26, 2026. Selected installation guidance advances
to proof-backed 0.3.0. Package access remains a technical preview.

The maintainer authorized this version train on September 20: "probably a good
time for a version bump train too then". The approved sequence is GitHub
pre-release assets, TestPyPI proof, PyPI proof, then Homebrew proof. Internal Rust
crates and future distribution channels remain unpublished.

`1e356f3c862ab6844ea81da6b2da9c6bd4a8572d`. Version
[PR #1457](https://github.com/depsilon/shardloom/pull/1457) merged at
`c0af36f40182f8d86b73413fe22481e2c67ed5b7`, accepted head
`a69218f6cfddb9386e18996f591cbc322fbe7107`, with all 40 remote checks passing.

The version PR's review identified absolute checkout paths in the five
`changed_package_version_sources` entries. Those entries now use repository-
relative paths, matching the previous release record. Their bytes, hashes,
tested revision and local command-log custody remain unchanged. Each source hash
is verified in both a separate publication checkout and an extracted Git archive.
This documentation correction does not change package versions or runtime code.

Package access remains a technical preview. General native operator completion,
broader spill transitions, production-scale serving acceptance and the requested
subsequent ingest/storage work remain open. This release does not promote those
capabilities or enable any external-engine fallback. The September 26 maintainer
scope override is to finish this release and its records/merge, then stop; those
implementation and profiling queues do not resume automatically.
