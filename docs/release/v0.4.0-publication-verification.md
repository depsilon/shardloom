# ShardLoom v0.4.0 publication verification

Status: all four selected 0.4.0 package channels are published and their
installation proofs pass. The production website is deployed and verified
against the accepted publication commit. The selected package contract is 0.4.0.

## Release source

The shared native engine merged in [PR #1518](https://github.com/depsilon/shardloom/pull/1518),
analytic frames in [PR #1519](https://github.com/depsilon/shardloom/pull/1519),
and fresh release UAT in [PR #1520](https://github.com/depsilon/shardloom/pull/1520).
The final release source is `d9ccd11d069f16fd57bc84b944c54672f09351bc`, tree
`c548cc88b3ff71947d592bafa3fee45b7461bd44`. Its tree equals the accepted PR
head. [Exact-source CI](https://github.com/depsilon/shardloom/actions/runs/37383859663)
passed all 35 jobs. The PRs had no submitted reviews; primary review and passing
checks are recorded separately from unavailable review-bot approval.

The [resumed-source acceptance record](evidence/v0.4.0-resumed-source-acceptance-2026-10-05.json)
retains the exact CI job observations, accepted PR heads and merge identities,
portable release-build receipt, and the source comparison against the fresh
UAT build. Rust runtime sources, Python runtime sources and Cargo manifests and
lockfile are unchanged across that comparison; report and packaging-proof files
have their own recorded changes.

The [fresh UAT](../benchmarks/release-candidate-fresh-uat-2026-10-05.md) records
53.069432 seconds for replacement ingest of 99,997,497 rows, all 129 Full43
result comparisons, and 1,408 complete workflow records. The 68.219750-second
sum of per-query minima is not an observed end-to-end workflow duration.
Those measurements retain their own frozen executable and source identities.

## Scope

This is a technical preview. Package access does not establish production
readiness, broad SQL/DataFrame parity, performance superiority or completion of
the remaining type, adapter, resource, spill and recovery work. Vortex remains
the highest-fidelity native output. Internal Rust crates remain unpublished.
The [release notes](v0.4.0-release-notes.md) retain capability and timing scope;
the October 3 source-validation packet remains historical evidence.
