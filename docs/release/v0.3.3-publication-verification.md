## Scope

The [release notes](v0.3.3-release-notes.md) cover shared string aggregation,
bounded dictionary preparation, native reader lifetime and metadata admission,
the README/site refresh, and compatible dependency updates. Native Vortex
preparation still preserves the source layout; this release does not make every
I/O path produce the same optimized layout. The interrupted format pulse and
large text-format performance tests remain paused.

Package access does not establish production readiness, competitive superiority,
broad SQL/DataFrame parity, broader spill/recovery or serving fairness.
Unsupported execution remains explicit and must not use external-engine fallback.
Vortex remains the highest-fidelity native output. Internal Rust crates remain
unpublished. The authorized ship/drop campaign resumes after closeout from the
refreshed profile and a new finite candidate packet. Useful smaller gains remain
eligible; performance runs stay sequential.

under `/Users/dylan/LocalData/shardloom/release-0.3.3-20260930/`.
