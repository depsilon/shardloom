but left a process-group member, so the verifier drained it and stopped before
changing the installation. Homebrew's source documents a detached analytics
request; disabling analytics made the same bounded probe and full proof pass.
The original receipt did not identify the child executable. The failed receipt,
successful probe and qualified recovery explanation are retained in the transcript.

The Homebrew source checks overlapped the remote PyPI builds; tap publication
followed passed PyPI verification. GitHub's PR write API returned server errors,
so an ordinary Git merge and non-force push completed the reviewed change.
GitHub confirms PR #4 is merged. No branch protection or check was disabled.

## Completion boundary

Local integration validation passed: 246 release-script tests (two existing skips),
four registry-observer tests,
strict package-channel readiness using the exact release-source CI package/dependency
reports and local GitHub asset provenance, approved final-release verification,
version-source contracts, generated support docs, public status, release-track and
governance checks. Astro reported zero errors, warnings or hints; the 45-page build,
website readiness and static-asset validation passed. The publication-records PR
provides the final source-tree CI checks before merge.

The registry correction adds readiness checks for channel, complete artifact digests,
source/workflow identities pinned to the approved channel builds, checksum/SBOM contents
and transcript linkage. Three new test methods cover fifteen rejection mutations within
the release-script suite. The shared publication contract keys expected source commits and
workflow runs by release version; another release cannot reuse these identities by default.
It independently pins the exact three wheel filenames and one sdist filename and their
count, rejecting evidence sets that consistently omit a published distribution.

All four selected channel proofs now support the `0.2.4` installation guidance.
Historical `0.2.3` transcripts and pre-bump UAT evidence remain intact. The 116
open phase items and PERF/CG gates remain open. Publication does not establish
production readiness, competitive superiority, broader SQL/DataFrame coverage,
additional runtime platforms, or new distribution channels. No external-engine
fallback is enabled.
