Find an operation

Section titled “Find an operation”
Task Command family
Execute supported work run
Prepare source data as a reusable Vortex file prepare
Inspect planned work and boundaries route, explain, estimate
Inspect capabilities or setup capabilities, status, doctor
Read exact command arguments help COMMAND
Discover application command metadata command-metadata --audience application --format json
Discover maintainer tooling command-metadata --audience maintainer --format json
Generate shell completion command-metadata --completion bash (also zsh or fish)

The installed registry is the authority for arguments and available commands. Unfiltered metadata also includes maintainer smoke/rehearsal commands. Application help and completion use the application vocabulary; the audience option selects the metadata you need. See the reference for callable signatures and contributor tooling.

Plan/capability inspection is not query execution. Writers require explicit destinations and follow the format and write contract.
