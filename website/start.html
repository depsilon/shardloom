Start

Install. Read. Run.

ShardLoom v0.3.3 is available as a local technical preview. Start with a package, bring a local file, and use Python, SQL, or the CLI to run admitted native operations.

1. Install a package

Choose PyPI for Python or Homebrew for the CLI. Check package installation for platform requirements, bundled CLI support, and exact release commands.

Terminal
python -m pip install shardloom

# Or install the CLI with Homebrew
brew install depsilon/tap/shardloom

2. Bring a local file

Save this small CSV as data/orders.csv, creating the data directory first. The next query returns the two paid orders.

data/orders.csv
order_id,status
1,paid
2,pending
3,paid

3. Run and inspect

Compatibility inputs prepare through Vortex. Unchanged sources can reuse their prepared artifact; each call still executes its query. Inspect row count and no-fallback evidence, then try the Python guide or input/output reference.

Python
import shardloom as sl

ctx = sl.context()
result = (
    ctx.read("data/orders.csv")
       .filter(sl.col("status") == "paid")
       .limit(10)
       .run()
)

print(result.envelope.field_int("output_row_count"))
print(result.envelope.human_text)
print(result.fallback_attempted, result.external_engine_invoked)

Or run the same query with the CLI

Homebrew installs the CLI. From the directory containing data/orders.csv, run this command to return the same two paid orders with native execution evidence in JSON. No Python package is needed for this path.

Terminal · Homebrew
shardloom run sql --input data/orders.csv --sql "SELECT * FROM 'data/orders.csv' WHERE status = 'paid' LIMIT 10" --request collect --format json
